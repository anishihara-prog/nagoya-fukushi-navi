# 手動テスト手順書（障害福祉支援ナビ なごや）

自動テスト（`npm test` / `npm run test:e2e`）でカバーしきれない見た目・操作感・
実ブラウザ挙動を人が確認するための手順書。リリース前や大きめの変更後に実施する。

## 環境・事前準備

| 項目 | 内容 |
|---|---|
| 起動 | `npm start`（`serve` + cloudflared）または `npx serve -l 5500 .` → `http://localhost:5500/` |

| 事前クリア | DevTools → Application → Local Storage の `fukushi-navi-entries-v4` と `fukushi-navi-entries-v4-source` を削除してからリロード（最新の `data/entries.json` で開始するため） |
